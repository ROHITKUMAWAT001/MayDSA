## 📝 File Naming Convention

All files follow the **LeetCode-style naming format** for easy reference and searchability:

### Format
```
LC_[PROBLEM_NUMBER]_[ProblemName].java
```

### Examples
- `LC_0206_ReverseLinkedList.java` — LeetCode Problem #206
- `LC_0125_ValidPalindrome.java` — LeetCode Problem #125
- `LC_Basic_LinkedListImplementation.java` — Foundational/non-LeetCode problem
- `LC_Practice_RecursionConcepts.java` — Practice/multi-concept file

**Benefits:**
✅ Instantly recognizable problem numbers  
✅ Easy to cross-reference with online judges  
✅ Consistent naming across the entire repository  
✅ Simple grep/search for specific problems

## 🚀 How to Use This Repository

### Finding a Problem
```
1. Identify the difficulty level: Easy, Medium, or Hard
2. Navigate to the relevant topic folder
3. Open the file with LeetCode problem number in the name
4. Cross-reference the problem on LeetCode using the LC_ number
```

### Adding New Problems
```
1. Determine the difficulty level (Easy/Medium/Hard)
2. Determine the topic (Linked-List, Arrays, Trees, etc.)
3. Create the file in: [Difficulty]/[Topic]/
4. Follow naming convention: LC_[NUMBER]_[ProblemName].java
5. Implement your solution
```

### Example Workflow
```
To add a solution for LeetCode #1 (Two Sum), which is an Easy Array problem:
- Create file: Easy/Arrays/LC_0001_TwoSum.java
- Place solution in that file
```
